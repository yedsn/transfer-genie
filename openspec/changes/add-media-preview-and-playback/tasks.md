# Tasks

## 1. 预览资源路径与视频提帧基础

- [x] 1.1 定义版本化远端预览路径、本地端点缓存路径、媒体稳定键和图片旧 `.thumbs` 回退规则，并通过 Rust 单元测试验证年月分桶、特殊文件名、端点隔离和兼容路径。
- [ ] 1.2 为 Windows 与 macOS 支持架构接入固定版本 FFmpeg sidecar 及打包配置，补充第三方许可说明，并通过构建检查确认开发与发布路径都能定位可执行文件。
- [x] 1.3 实现受超时和输出限制保护的视频提帧函数，使用独立参数调用 sidecar 并输出标准 JPEG，通过测试或受控 fixture 验证成功提帧、文件名含空格、无效视频和超时回退。
- [x] 1.4 抽取统一图片/视频预览生成器，限制尺寸和后台生成并发，通过 Rust 测试验证图片生成、视频生成、非媒体跳过及生成失败不传播为原上传失败。

## 2. 上传链路与预览图获取

- [x] 2.1 重构文件上传核心，在稳定本地源可用后异步生成并上传新版图片/视频预览图，确保临时上传源不会提前清理，并通过 Rust 集成测试覆盖路径上传和字节上传。
- [x] 2.2 验证本机 HTTP、剪贴板/数据上传及其他复用发送核心的入口均产生相同预览行为，通过入口级测试确认原文件成功、预览失败回退和上传历史不受影响。
- [x] 2.3 新增携带端点和稳定资源身份的通用预览图解析命令，按新本地缓存、新远端资源、旧图片本地缓存、旧图片远端资源顺序解析，通过命令测试覆盖命中、下载缓存、404 和端点切换。
- [x] 2.4 将消息删除与媒体预览资源清理联动，限制所有本地删除在应用管理目录内，并通过测试验证仅本地删除、远端删除、清理失败不阻断主操作及旧缩略图兼容清理。

## 3. 媒体播放缓存与后端接口

- [x] 3.1 定义播放源解析输入输出、缓存状态和进度事件，区分上传本地文件、正式下载文件、预览缓存和远端缓存来源，并通过序列化测试固定前后端字段契约。
- [x] 3.2 实现通用媒体播放源解析命令，依次复用已有本地文件、正式下载文件和预览缓存，否则完整缓存远端文件后返回本地路径，通过 Rust 测试覆盖各解析分支。
- [x] 3.3 为同一端点与资源键的播放缓存请求实现去重、进度、取消、临时文件清理和完成后原子落盘，通过异步测试验证并发请求只下载一次、失败可重试且不留下不完整缓存。
- [x] 3.4 确保播放缓存不更新消息 `local_path`、下载历史或批量下载状态，通过数据库和命令级测试验证仅存在播放缓存的媒体仍被识别为未正式下载。
- [x] 3.5 实现播放缓存容量/保留期维护和最近使用清理，保护当前播放文件且不触及下载目录，通过文件系统测试验证超限清理顺序、端点隔离及越界路径防护。
