## MODIFIED Requirements

### Requirement: Message file storage
客户端 SHALL 将每条外发消息存储为 WebDAV 根目录下 `files/` 子目录中的单个文件。
文本消息 MUST 使用 UTF-8 `.txt` 文件；文件消息 MUST 保留原始字节与扩展名。
当用户通过编辑器发送按钮或发送快捷键发起发送时，客户端 SHALL 先基于当前编辑器内容和已选文件创建发送快照，立即清空编辑框并释放已选文件列表，然后在后台执行 WebDAV 上传、history 更新、本地索引刷新和发送后复制等后续逻辑。后台发送不得覆盖用户随后在编辑框中输入的新内容。若编辑器处于全屏状态，客户端 SHALL 在后端确认发送成功后立即退出全屏，不得等待消息列表刷新完成。

#### Scenario: Text message upload
- **WHEN** 用户发送文本消息
- **THEN** 客户端向 WebDAV `files/` 目录上传单个 `.txt` 文件
- **AND** 本地消息索引记录发送者、时间戳、大小与内容

#### Scenario: File message upload
- **WHEN** 用户发送文件
- **THEN** 客户端向 WebDAV `files/` 目录上传原始文件字节
- **AND** 保存的文件保留原始扩展名

#### Scenario: Composer is released before background send completes
- **WHEN** 用户通过编辑器发送按钮或发送快捷键发送非空草稿
- **THEN** 客户端立即清空编辑框
- **AND** 发送中的消息可以在列表中显示为待发送状态
- **AND** WebDAV 上传、history 更新和本地消息刷新在后台完成
- **AND** 用户随后输入的新草稿内容不会被后台发送结果覆盖

#### Scenario: Fullscreen exits before feed refresh completes
- **GIVEN** 编辑器处于全屏状态
- **WHEN** 后端确认消息发送成功
- **THEN** 客户端立即退出编辑器全屏状态
- **AND** 退出全屏不等待本地消息列表刷新完成

### Requirement: Message feed display
客户端 SHALL 提供按时间排序的聊天式列表，并显示发送者名称、时间戳与文件大小。
文本消息 SHALL 显示全文内容并提供复制按钮。
文件消息 SHALL 显示文件名并提供下载按钮及“更多操作”菜单中的另存为动作。
语音转写生成的消息 SHALL 以文本消息样式展示转写结果，并显式提供一个源音频播放器。该播放器 SHALL 支持播放、暂停、展示播放进度，并允许用户拖动进度到任意位置继续播放。
语音转写消息 SHALL 默认展示润色后的文本；当存在润色前原文时，客户端 SHALL 提供切换控件以查看原文。
语音转写消息的复制动作 SHALL 复制当前切换模式对应的完整文本：润色后模式复制润色后文本，原文模式复制润色前原文。
语音转写消息的主下载动作 SHALL 下载其关联的源音频文件，同时客户端 SHALL 保留单独下载转写文本的入口。
消息列表中的文本预览 SHALL 受长度限制；当文本超出预览上限时，客户端 SHALL 仅在列表中展示安全的预览内容，并提供查看完整内容的入口。
**所有消息 SHALL 直接显示一个用于“标记”或“取消标记”的图标。**

#### 场景: 标记一条消息
- **当** 用户点击消息上的“标记”图标
- **那么** 该消息应被标记
- **并且** 消息上的“标记”图标应高亮显示。

#### 场景: 取消标记一条消息
- **当** 用户点击已标记消息上的“标记”图标
- **那么** 该消息应被取消标记
- **并且** 消息上的“标记”图标应恢复默认状态。

#### 场景: 播放语音消息源音频
- **假如** 消息是由语音录入转写生成的文本消息
- **当** 用户查看该消息上的源音频播放器
- **那么** 客户端应加载与该消息关联的原始音频文件
- **并且** 用户可以播放、暂停、查看播放进度，并拖动进度条跳转播放位置
- **并且** 播放行为不应要求用户先下载文件到独立目录。

#### 场景: 下载语音消息源音频
- **当** 用户点击语音转写消息上的主下载按钮
- **那么** 客户端应下载该消息关联的源音频文件
- **并且** 用户仍可通过明确入口下载转写文本。

#### 场景: 查看语音消息原文
- **假如** 语音转写消息同时保存了润色后文本和润色前原文
- **当** 用户查看该消息
- **那么** 默认应显示润色后的文本
- **并且** 用户可以切换查看润色前原文

#### 场景: 复制当前模式的语音文本
- **假如** 用户将语音消息切换到“原文”模式
- **当** 用户点击复制按钮
- **那么** 应复制完整的润色前原文
- **并且** 切换回“润色后”模式后，复制按钮应复制完整的润色后文本。

#### 场景: 限制列表文本预览长度
- **假如** 文本消息内容超过列表预览上限
- **当** 客户端渲染消息列表
- **那么** 列表中只展示受限长度的预览文本
- **并且** 用户可以通过详情页、双击打开详情页或下载后查看完整内容。

### Requirement: 删除范围与效果
客户端 SHALL 在删除确认时提示删除范围（仅本地或本地+远端）。

仅本地删除时，系统 SHALL 删除本地消息记录，并删除文件消息对应的本地已下载文件；对于语音转写生成的消息，系统 SHALL 同时清理其关联的源音频引用。

本地+远端删除时，系统 SHALL 删除 WebDAV `files/` 中对应文件，并从远端 `history.json` 移除条目，同时删除本地消息记录与已下载文件；对于语音转写生成的消息，系统 SHALL 同时清理其关联的源音频引用。

#### Scenario: 仅本地删除
- **WHEN** 用户确认仅本地删除
- **THEN** 选中的消息从本地列表移除
- **AND** 文件消息对应的本地已下载文件被删除
- **AND** 语音转写消息的关联源音频引用被清理。

#### Scenario: 本地+远端删除
- **WHEN** 用户确认本地+远端删除
- **THEN** 远端 WebDAV 文件与 history 条目被删除
- **AND** 本地消息记录与已下载文件被删除
- **AND** 语音转写消息的关联源音频引用被清理。

#### Scenario: 远端删除失败
- **WHEN** 远端删除失败
- **THEN** 客户端提示错误并保留失败的消息记录。
