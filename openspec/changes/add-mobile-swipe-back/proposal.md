# Proposal

## Why

移动端消息详情和全屏消息编辑器目前主要依靠关闭按钮返回，单手操作不够方便。增加明确且可取消的滑动手势，可以让用户更自然地返回消息列表，同时避免误触造成草稿丢失。

## What Changes

- 在移动端顶层消息详情和现有全屏新消息／草稿编辑器中，支持从屏幕右侧边缘向左滑动返回主窗口，并提供跟手及取消反馈。
- 编辑器返回前确认当前草稿已安全保存；保存失败或附件选择、发送正在进行时不得通过该手势关闭编辑器。
- 避免与纵向滚动、横向滚动、文本编辑及选择、系统手势和嵌套弹层冲突；保留现有关闭按钮及无障碍操作。
- 本次不新增已发送消息正文编辑功能，也不改变其他弹窗或桌面端交互。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `message-feed`: 增加移动端消息详情及消息草稿编辑器的滑动返回与草稿保护要求。

## Impact

- 影响移动端 Vue 窗口、手势状态与样式，以及消息草稿保存流程和相应测试。
- 不引入服务端协议、数据库结构或桌面端行为变更；需在 iOS Simulator 验证，随后进行真机验收。
