# 下载机器人设计

## Context
现有内置插件的注册键是 image-downloader，目标实例已有稳定 UUID。宿主准备附件时整件读入内存并硬编码 100 MiB 上限，对文字引用仅提取 URL。插件自身也有上限和图片签名检查。现有同步目录按空间存储，任务包含目标实例、正文和引用，旧执行端仅消费协议版本 1 的任务。

## Goals / Non-Goals
目标是让同一机器人从电脑或手机接收通用文件，按每次调用选择执行电脑上的下载出口。代理仅用于外部 HTTP(S) 文件链接；WebDAV、Supabase 私有附件继续由宿主按空间权限和原件版本读取。首版代理协议采用 HTTP，支持通过 CONNECT 下载 HTTPS 文件。视频站点页面解析、BT 和后台 aria2 RPC 服务不在范围内。

## Decisions

### 身份、目录和混合版本
保留内部插件 ID、实例 UUID 与执行历史，替换内置资源并更新 manifest 能力。迁移旧默认显示名、补齐缺失配置，保留用户设置。在获准空间目录中发布下载图标的枚举值、功能版本、代理公开条目和默认出口。客户端用本地图标渲染；回复保留图标类型快照，以便离线展示。普通机器人继续显示通用图标。

新增能力由实例声明。使用新行为的调用采用独立任务协议版本，旧执行端已有版本检查，可避免缓存过期或执行端降级后把显式代理任务当成直连。升级后的执行端同时读取旧图片任务和新任务，旧图片任务和其重试沿用旧输入解释、命名和恢复记录。旧发送端仍可调用原图片能力；对新版本任务使用新的能力校验。两种 Provider 同步同一组可选公开字段，并核对 Supabase RPC 的版本与字段校验，必要时增量迁移。

### 提取可保存的项目
依据结构化目标及提及范围剥离本次调用标记，保留引用中的完整原文和用户手写的其他 @ 字符。纯链接列表逐个下载；有说明文字与链接时，保存一份完整原文并下载去重的链接；仅提及加引用不产生额外说明文件。引用文本使用发送时的完整正文，附件核对版本并取得原件。每条文字以消息 ID、附件以引用身份、链接以 URL 形成稳定项 ID，以支持部分重试。无文件名的直链优先采用响应提供的安全名称，其次采用 URL 末段，最后生成稳定名称。图片输入继续校验类型，媒体观看页返回 HTML 时不伪装为视频；明确下载的 HTML 文件可以作为普通文件保存。

### 下载、命名与恢复
内置下载器和 aria2c 都写入任务专用临时文件。宿主及插件以流式读写、累计实际字节和增量哈希替换固定 100 MiB 缓冲，支持设置超过 100 MiB 的单项上限。宿主把执行电脑的保存文件名规则与各项消息时间交给内置插件，插件在取得原始文件名后调用和普通下载相同的渲染函数。文字以“文字_消息时间.txt”作为原名。已有插件前缀配置在启动时清理，已完成项按原记录恢复。取消或超时时终止对应下载进程并清理临时数据，重试前核实已发布文件。

### 设置、公开目录与提及
每个命名代理在执行端生成稳定 ID，保存名称、代理地址、可选认证引用。认证材料写本机凭据库。列表提供新增、编辑、删除和经当前引擎实际发请求的连接测试。默认设置保存 direct 或指定 ID。仅将 ID、名称及默认选择映射为公开目录数据；用户对外可见的代理名称应与地址分开。目录更新与空间撤权沿用实例发布机制。

点击已选提及打开本次调用菜单，支持文本、Markdown、桌面键盘和移动触屏。每个作用域的草稿绑定目标实例和选项；更换目标时回到跟随默认。任务存储 default、direct 或 profile 加 ID，发送事务与幂等比较包含这一选项。首次开始执行前持久化解析出的出口 ID；“跟随默认”以该时刻为准。删除代理、认证失效或代理连接异常产生明确的逐项失败。重试保留原出口 ID，需更换出口时以新调用显式选择。

### 两种下载引擎
选择内置引擎无需安装工具。选择 aria2c 时提供本机文件选择及版本检查，使用独立参数启动短时子进程，控制目标文件、HTTP(S) 输入、超时和取消。两种引擎在直连时显式排除环境或 aria2 用户配置中的代理；指定代理时排除环境直连例外。代理凭据不得出现在命令行、诊断输出或同步记录。若底层工具需私有配置，使用受限、短期的本地文件并清理，过滤工具错误输出。两个引擎共用文件发布、哈希和恢复逻辑。

## Risks / Trade-offs
- 代理设置只同步摘要，离线候选可能过时。执行时按 ID 再校验，删除重建同名代理不能代替原代理。
- 外部程序可能自行预分配大文件。限制实际写入、限制重定向、关闭不受控的预分配并覆盖无 Content-Length 的响应；错误或取消不发布部分文件。
- 图片插件的基线规范在另一进行中的变更内。先归档基线，再归档本变更；两组测试分别保留旧任务语义和通用下载语义。

## Migration Plan
迁移本机注册记录及配置后重新发布受支持的能力；发送端按目标能力决定可用选项。降级前停止接收新任务并保留配置、任务记录和暂存状态；旧版本不得代为执行已有新版本任务，恢复新版后按原 ID 核实状态。
