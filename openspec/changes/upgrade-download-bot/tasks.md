# 实施任务

- [x] 1.1 升级内置 manifest、注册迁移与图标元数据。用已有自定义名称、目录、授权和实例 UUID 的注册表验证重复启动只保留一个实例。
- [x] 1.2 扩展目录与任务版本、按次出口和发送幂等键，并更新插件协议文档。用新旧发送端、执行端及降级样本验证旧任务可恢复、旧执行端跳过新任务。
- [x] 1.3 验证 WebDAV 与 Supabase 目录和任务往返均保存公开选项并隔离空间；断言原始同步载荷中不存在代理地址、路径和凭据。

## 2. 通用输入及文件发布

- [x] 2.1 对附件、完整文字、链接和混合正文生成稳定输入项；用含同名文件、换行、重复 URL、手写 @、空调用的样本核对顺序、文本内容和项数。
- [x] 2.2 对宿主原件获取与内置直链改用有界流式写入，接入现有恢复记录。验证大于 100 MiB 的视频、同名避让、部分失败、取消和落盘后崩溃恢复。

## 3. 执行端代理与引擎

- [x] 3.1 实现代理列表及稳定 ID、凭据存储、默认值和删除替换。用新增、改名、删除再同名创建验证引用身份，核查配置和日志脱敏。
- [x] 3.2 在执行电脑实现连接测试、直连和指定代理，持久化首次解析的出口。使用本地代理与 HTTP 服务记录请求，验证默认、直连、认证失败、离线改名和删除后重试。
- [x] 3.3 实现 aria2c 路径选择、版本检查及子进程下载。用真实可执行程序验证含空格路径、代理、超限和取消回收；模拟不可执行程序时确认仅直链项失败。
- [x] 3.4 在启用的下载插件设置页提供下载目录、大小限制、引擎、程序路径及命名代理列表。按界面完成添加、测试、设为默认、删除并重新打开确认持久化，更新对应使用说明。
