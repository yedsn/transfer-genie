## 3. 选择模型与批量操作

- [x] 3.1 实现基于稳定资料键的选择集合、大小汇总和各视图选中状态派生，并通过单元测试验证跨页、跨分类、跨筛选和切换查看方式后选择不丢失。
- [x] 3.2 实现资料项点击、复选框选择、全选当前页、取消当前页选择和清空全部选择，并通过 UI 测试验证已选数量、合计大小和无选择时禁用提交。
- [x] 3.3 接入“全选全部筛选结果”解析命令，将返回的冻结键集合并入已有选择，并通过集成测试验证不会选中调用之后新同步的资料，也不会清除其他筛选条件下的选择。
- [x] 3.4 实现约 300ms 长按阈值、移动容差、选中/取消刷选模式、单次去重和完整 Pointer Events 清理状态机，并通过浏览器交互测试覆盖轻点、滚动、连续刷选、连续取消和 pointer cancel。
- [x] 3.5 为刷选实现上下边缘自动滚动，并通过交互测试验证滚动期间新经过资料持续按当前模式处理且松开后停止滚动。
- [x] 3.6 在平铺、小图标和大图标视图实现空白区域矩形框选及实时预选，在详细信息和列表视图禁用框选，并通过交互测试验证相交选择、不清除旧选择和视图限制。

- [x] 4.1 实现提交前的资料快照和状态检查，计算需要下载、可续传、需重新下载及已完整存在的跳过数量，并通过 Rust/前端测试验证本地文件存在、丢失和部分下载场景。
