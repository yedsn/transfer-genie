# Change: 收起编辑器草稿标签页

## Why

同时打开较多草稿时，标签栏拥挤，用户需要暂时收起不常用草稿，只保留关注的标签，同时不丢失任何草稿内容。探索阶段已确认交互，用户已要求退出 explore 并开始实现。

## What Changes

- 右键菜单增加“收起当前”和“收起其他”，每栏至少保留一个可见标签。
- 标签栏右侧提供“已收起 N 个”列表，支持恢复单个并切换过去，以及全部展开。
- 收起不改变草稿正文、名称、格式、来源或顺序；状态随现有本地工作区持久化。
- 兼容关闭、跨栏移动、分栏和可见标签拖动排序，不改变标记分类标签或远端协议。

## Capabilities

### New Capabilities

- `editor-tab-visibility`: 草稿标签的非破坏性收起、恢复与本地状态恢复。

### Modified Capabilities

无。

## Impact

- 工作区核心状态、响应式 store、标签栏及样式。
- 工作区纯逻辑与真实浏览器回归测试。
- 无新增依赖，无 Rust 或远端数据变更。
