## Context

每个编辑器分栏已有完整 tabs 数组、活动标签 ID、SortableJS 和本地工作区持久化。收起必须独立于会删除其他分栏草稿的“单栏”功能。

## Decisions

- 在标签上增加布尔 `collapsed`，保留其在原 tabs 数组的位置。旧数据缺少该字段时视为未收起。
- 统一维护非空分栏至少一个可见标签且活动标签可见。关闭或移走最后一个可见标签时，恢复一个剩余标签；收起活动标签时优先切换右侧、其次左侧的可见邻居。
- 单个恢复使用现有激活链路；全部展开保持原活动标签与完整顺序。
- 收起列表使用页面级浮层，避开分栏 overflow 裁剪，支持点击外部与 Escape 关闭，并把焦点归还触发入口。
- SortableJS 只渲染可见标签；提交移动时根据移动后 DOM 中下一个可见标签 ID 映射回完整数组插入位置，避免把可见索引误当作完整索引。
- 沿用既有本地持久化，不同步 UI 偏好到 WebDAV 或 Supabase。

## Verification

纯逻辑覆盖不可变性、内容与顺序保留、可见性不变量、分栏隔离、旧数据和序列化恢复、关闭与停靠；浏览器覆盖菜单操作、恢复、刷新恢复、收起时拖动及浮层可达性。
