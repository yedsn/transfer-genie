# 第一次传输

这份文档帮助你完成第一次成功的文本或文件传输，确认 Transfer Genie 已经可用。

## 1. 配置 WebDAV

在设置页中完成：

- WebDAV 地址
- 用户名
- 密码
- 当前活动端点

建议先使用一个你确认可读写的目录，避免把问题混在权限配置里。

## 2. 发送一条文本

回到首页：

1. 在输入框里输入一段文本
2. 点击发送
3. 等待消息出现在时间线中

如果发送成功，通常说明：

- 当前活动端点有效
- WebDAV 写入正常
- 本地消息流工作正常

## 3. 再发一个文件

接着上传一个小文件做验证：

1. 选择文件
2. 点击发送
3. 在消息流和传输任务中观察进度

## 4. 常见验证点

完成第一次传输后，建议顺手确认：

- 消息流里能看到文本和文件记录
- 文件可以下载
- 发送者名称和时间线显示正常
- 重启应用后历史记录仍能恢复
