# 跨设备同步文字、链接和 Markdown

Transfer Genie 可以用来在多台设备之间发送文字、链接、命令片段和 Markdown 内容。它把文本当作消息写入 WebDAV 消息流，另一台设备同步后即可查看。

## 适合什么场景

| 场景 | 说明 |
| --- | --- |
| 在电脑之间传一段文字 | 例如链接、命令、配置片段、临时备注。 |
| 不想通过聊天软件转发 | 文本进入自己的 WebDAV 存储，而不是进入第三方 IM 平台。 |
| 需要保留历史 | 消息流会保留时间线，后续可以回看和筛选。 |
| 需要 Markdown | 发送内容可以指定为普通文本或 Markdown。 |

## 使用方式

1. 打开 Transfer Genie 首页。
2. 在输入区域填写文字、链接或 Markdown 内容。
3. 发送后，内容会上传到当前活动 WebDAV 端点。
4. 其他设备同步后，可以在同一条消息流中看到这段文本。

## 可以传哪些内容

| 内容类型 | 示例 |
| --- | --- |
| 普通文本 | 会议记录、临时备注、账号说明中的非敏感部分。 |
| 链接 | 文档链接、下载链接、网页地址。 |
| 命令片段 | `cargo test`、`npm run docs:build` 等临时命令。 |
| Markdown | 待办、说明、格式化文本。 |

## 和剪贴板同步有什么区别

剪贴板同步通常只保留最近一次复制内容。Transfer Genie 更像一个文本收件箱：每条内容都有发送时间、发送者和历史记录，适合跨设备保留多个片段。
