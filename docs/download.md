# Transfer Genie 下载

Transfer Genie 是一个基于 WebDAV 的跨设备文件传输与文本同步桌面应用。下载后配置一个 WebDAV 端点，就可以在 Windows 和 macOS 之间发送文本、Markdown、链接和文件。

## 下载入口

| 入口 | 用途 |
| --- | --- |
| [GitHub Releases](https://github.com/yedsn/transfer-genie/releases/latest) | 获取最新版本安装包和发布说明。 |
| [GitHub 仓库](https://github.com/yedsn/transfer-genie) | 查看源码、Issue、README 和构建状态。 |
| [Gitee 镜像](https://gitee.com/hongxiaojian/transfer-genie) | 国内网络环境下查看项目镜像。 |

## 选择哪个安装包

| 系统 | 建议 |
| --- | --- |
| macOS | 优先下载最新 `.dmg` 安装包，拖入 `Applications` 后启动。 |
| Windows | 优先下载最新 Windows 安装包，例如 NSIS 安装器。 |

如果当前版本没有适合你系统的安装包，可以参考开发文档从源码运行：[`/develop/setup`](/develop/setup)。

## 安装后第一步

安装完成后，先配置 WebDAV：

1. 打开 Transfer Genie。
2. 进入设置页。
3. 填写 WebDAV 地址、用户名和密码。
4. 将该端点设为当前活动端点。
5. 回到首页发送一条文本或一个文件做验证。
