## Default Permission

Allows the Transfer Genie mobile integration diagnostic command.

#### This default permission set includes the following:

- `allow-diagnostic`
- `allow-set-navigation-gestures-enabled`
- `allow-navigate-native-page`
- `allow-select-media`
- `allow-select-documents`
- `allow-preview-file`
- `allow-share-file`
- `allow-generate-image-thumbnail`
- `allow-generate-video-poster`
- `allow-cancel-video-poster`
- `allow-list-shared-imports`
- `allow-stage-shared-imports`
- `allow-acknowledge-shared-imports`
